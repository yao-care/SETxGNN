# Gadodiamid: Från diagnostisk kontrastförstärkning vid MR till reumatoid artrit

---

## Sammanfattning

Gadodiamid (Omniscan) är ett gadoliniumbaserat kontrastmedel som används för att förstärka bilder vid magnetresonanstomografi (MR). Det är alltså ett diagnostiskt läkemedel och inte en behandling. TxGNN-modellen förutsäger att det kan vara effektivt mot **reumatoid artrit**, men det finns **inga kliniska prövningar** och endast **3 publikationer**. Alla tre beskriver MR-undersökning av leder och inte någon behandlingseffekt.

## Varför är denna förutsägelse rimlig?

För närvarande finns ingen detaljerad verkningsmekanismdata tillgänglig. Gadodiamid är ett paramagnetiskt gadoliniumkelat som förändrar de magnetiska egenskaperna hos omgivande vävnad, så att den syns tydligare vid MR. Det har ingen känd farmakologisk effekt på sjukdomsprocesser.

Den höga poängen (99,2 %) speglar sannolikt ett samband i kunskapsgrafen mellan läkemedlet och reumatoid artrit via bilddiagnostisk litteratur. De tre artiklarna använde MR av handled och fingerleder för att visa ledinflammation, erosioner och benmärgsödem. De visar inte att läkemedlet lindrar eller bromsar sjukdomen.

Någon rimlig terapeutisk mekanism för ett kontrastmedel vid reumatoid artrit finns därför inte. Förutsägelsen bör tolkas som ett diagnostiskt samband och inte som ett behandlingsförslag.

## Säkerhetsaspekter

- **Läkemedelsinteraktioner**: Totalt 109 möjliga interaktioner är registrerade. Av de som visas är nästan alla av okänd allvarlighetsgrad, bland annat kalcitriol, pantoprazol, laktulos, klotrimazol, omeprazol, lansoprazol, vankomycin, prednison, simvastatin och kaliumklorid. Interaktionen med **acebutolol** är klassad som **måttlig**.

Se produktresumén för varningar och kontraindikationer. Gadoliniumbaserade kontrastmedel är kända för risken för nefrogen systemisk fibros vid nedsatt njurfunktion samt för gadoliniumretention i vävnad. Dessa uppgifter finns inte i de data som sammanställts för rapporten och bör verifieras mot produktresumén.

## Slutsats och nästa steg

**Beslut: Avvakta**

**Motivering:**
- Gadodiamid är ett diagnostiskt kontrastmedel utan känd terapeutisk verkan vid reumatoid artrit, och den litteratur som finns rör enbart bilddiagnostik. Dessutom saknas giltiga godkännanden i Sverige.

**För att gå vidare krävs:**
- Oberoende mekanistisk evidens för en behandlande effekt, vilket för ett kontrastmedel är högst osannolikt.
- Prekliniska eller kliniska studier som visar sjukdomspåverkan, vilket för närvarande saknas.
- Komplett säkerhetsinformation från produktresumén, särskilt risken för nefrogen systemisk fibros och gadoliniumretention.
- Det andra förutsagda området, **osteoartritkänslighet** (99,1 %), saknar all evidens (evidensnivå L5). Det beskriver en genetisk riskbild snarare än ett behandlingsbart sjukdomstillstånd och bör inte prioriteras.
